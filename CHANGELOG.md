# Changelog

## 1.0.0 - 04-Nov-2026 — First shared font collection

- Provide a shared collection of 46 fonts for compatible World of Warcraft addons.
- Preserve each addon's own font settings and register fonts through LibSharedMedia.
- Include language coverage metadata for supporting addons.
- Install the collection once per game client and keep it enabled; choose fonts
  in the addon that uses them. The collection updates independently of its consumers.
- First release for Retail: Midnight. The separate Forever beta build remains
  in testing and is not included in this release.
- Thanks to [chenrylee](https://github.com/chenrylee) for suggesting a separate
  font package ([StatsPro #10](https://github.com/Antrakt92/StatsPro/issues/10)).
